# カズレーサー

`kazu` をどれだけ速く打てるかだけで勝負する、しょうもないタイピングレース。
全員カズなので、誰が勝ってもだいたいカズが勝ちます。

## 遊び方

1. `index.html` をブラウザで開く（サーバー不要）
2. **レース開始**
3. シグナルが5つ点灯 → **全部消えた瞬間に打ち始める**
   - 消える前に打つと **フライング**（カズが消し飛んでやり直し）
4. 表示された単語をひたすら打つ。1文字打つごとにカズが加速します
   - 打ち間違えると減速（速度が45%落ちる）
   - 単語を打ち切るとボーナス加速
5. ゴールすると 順位・タイム・ランク（S〜E）・打鍵数・実況コメントが出る

**日本語入力（IME）はONのままで大丈夫です。** キーの物理位置で判定しているので、
半角/全角を切り替えなくてもそのまま打てます。

スマホの場合は画面をタップするとキーボードが出ます。
25秒走り切れないとリタイアです。

## ランク目安

| ランク | トータルタイム |
|---|---|
| S | 6.00秒以下 |
| A | 7.00秒以下 |
| B | 8.00秒以下 |
| C | 9.50秒以下 |
| D | 11.50秒以下 |
| E | それ以上 |

トータルタイム = 反応時間 + 走行時間。
最速CPU「カズC」は約7.2秒で走ります。抜くにはだいたい **5打/秒** 必要です。
ベストタイムはブラウザに保存されます。

## 構成

```
kazu-racer/
├── index.html      # 全部これ1枚（HTML + CSS + JS）
├── assets/
│   └── kazu.png    # kazu-lazer から流用
├── README.md
└── PROGRESS.md
```

ライブラリ・ビルド・サーバーはどれも不要です。
チェッカーフラッグは画像ではなく CSS（`repeating-conic-gradient`）で描いています。
難易度や単語リストは `index.html` の「チューニング」ブロックで調整できます。
